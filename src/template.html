How to use

  • Click a node to see its details; double-click to focus on just its neighbourhood.
  • Drag a node to move it (it stays pinned), drag the background to pan, scroll to zoom.
  • Switch Files / Functions / Both at the top to choose what the connections are between.
  • ◉ Graph / ⇢ Flowchart: the flowchart lays files, Folders, Functions or Both (files pointing at the functions inside them) out as boxes in columns — entry points on the left, the things they rely on to the right. Arrows point from a file to what it uses.
  • Each filter group in the left panel has all / none links so you can clear everything and tick just one item.
  • Use the left panel to filter by language, connection type, symbol kind and folder.
  • Keys: / search · F fit · Esc clear selection · P pin/unpin selected.
  • Export ▾ → Interactive HTML snapshot saves one file that shows this exact graph on another PC.
